gta6 clipz Clipper is a desktop app that runs on the owner's own computer. It finds highlight moments in Twitch live streams, edits them into vertical videos with captions, and, when the user chooses a clip, posts it to the user's own TikTok and YouTube accounts.

  • Runs locally on Windows. There is no cloud service and no user database.
  • Sign-in to TikTok and YouTube happens in the user's own browser through the platforms' official login pages.
  • Nothing is posted unless the user picks the clip and adds it to the upload queue.
  • Every post credits the original streamer.
