Privacy Policy

Last updated: November 19, 2026

This policy covers the gta6 clipz Clipper desktop app ("the app").

What the app accesses

  • TikTok: through TikTok Login Kit, the app receives an access token and basic profile information (user.info.basic: open ID, display name, avatar). It uses this only to show which account is connected and to post videos the user has chosen (video.publish / video.upload).
  • YouTube: through Google OAuth, the app receives a token with the youtube.upload scope. It uses this only to upload videos the user has chosen.
  • Twitch: the app reads public live streams and public chat. It does not log in to Twitch.

Where data is stored

Everything stays on the user's own computer: access tokens, clips and settings. The app has no server. It does not collect analytics and does not send data anywhere except to TikTok, Google/YouTube and Twitch when it performs the actions above.

Sharing

No data is sold or shared with third parties. Videos are sent only to the platform the user queued them for.

Removing access and data

  • To revoke access: in TikTok, go to Settings → Security → Manage app permissions. For Google, go to myaccount.google.com/permissions.
  • To delete local data: delete the app's secrets folder (tokens) and clips folder (videos).
